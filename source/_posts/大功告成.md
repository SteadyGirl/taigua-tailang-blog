## 建立过程

全程都是豆老师手把手教我的：
- 注册github，创建仓库，不要加README
- 注册cloudflare
- 下载Node.js
	- node验证：弹出版本号就算下载成功
```
node -v
npm -v
```
- 下载hexo
```
npm install -g hexo-cli
```
- 创建blog文件夹，其中hexo s是本地预览；关于网页的所有操作都要在这个文件夹中进行。
```
hexo init blog
cd blog
npm install
hexo s
```
- [下载git](https://blog.csdn.net/mukes/article/details/115693833)并检验git版本
```
git --version
```
- 配置git
```
git init
git config user.name "你的GitHub用户名"
git config user.email "你的GitHub注册邮箱"
```
- 在blog文件夹增加`.gitignore`文件，文本内容为
```
.DS_Store
Thumbs.db
db.json
*.log
node_modules/
public/
.deploy*/
```
- 初次提交推送代码并授权
```
git add .
git commit -m "初始化博客"
git branch -M main
git remote add origin "你的github仓库https地址"
git push -u origin main
```
- cloudflare绑定github仓库，要选择pages而不是workers
	- build command填：
```
npx hexo generate
```
	- Build output directory填：
```
public
```
- 用记事本打开blog文件夹中的_config.yml文件,并修改url: 后面的网址
```
# URL
## Set your site url here. For example, if you use GitHub Page, set url as 'https://username.github.io/project'
url: http://example.com
```
- 你也可以修改前面的网站信息。注意英文:后面要加空格。改完用git保存执行上传。
```
# Site
title: Hexo      #改成你的博客名字
subtitle: ''     #博客副标题
description: ''  #博客简介
keywords:        #搜索关键词
author: John Doe #改成你的名字
language: zh-CN  #把 en 改成 zh‑CN，博客显示中文
timezone: 'Asia/Shanghai'  #时区
```
- 尝试处理第一个博客

原生：

| 字段               | 作用                  |
| ---------------- | ------------------- |
| `title`          | 文章标题，必填             |
| `date`           | 创建时间，`hexo new`自动生成 |
| `updated`        | 修改更新时间，可手动改写        |
| `tags`           | 标签，多条用 `-` 换行       |
| `categories`     | 分类，多条用 `-` 换行       |
| `layout: post`   | 文章布局，普通文章保持 post 即可 |

| `permalink`      | 自定义这篇文章的访问网址路径      |

| 字段            | 作用                    |
